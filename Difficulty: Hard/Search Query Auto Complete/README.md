<h2><a href="https://www.geeksforgeeks.org/problems/search-query-auto-complete/1">Search Query Auto Complete</a></h2><h3>Difficulty Level : Difficulty: Hard</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Design and Implement the <strong>AutoCompleteSystem</strong> class that handles users searches. </span><span style="font-size: 18px;">Users enter a query one character at a time. A query may contain multiple words separated by single spaces and always ends with the special character '#'.&nbsp; The class should have the following methods.</span></p>
<ul>
<li><span style="font-size: 18px;">AutoCompleteSystem(string[] sentences, int[] times): Constructor that i</span><span style="font-size: 14pt;">nitializes the system with historical search queries, where times[i] represents the frequency of sentences[i].</span></li>
<li><span style="font-size: 18px;">vector&lt;string&gt; input(char c) </span><span style="font-size: 14pt;">Processes the next character typed by the user. If c == '#', stores the completed query and returns an empty list. </span><span style="font-size: 14pt;">Otherwise, returns the top 3 historical sentences matching the current prefix according to the following ranking rules.</span></li>
</ul>
<p><span style="font-size: 18px;">Ranking Rules:</span></p>
<ul>
<li><span style="font-size: 18px;">Matching sentences are ranked in descending order of frequency (count of earlier searches).</span></li>
<li><span style="font-size: 18px;">If multiple sentences have the same frequency, they are ordered by <strong>ASCII</strong> (lexicographical) order, with the smaller one appearing first.</span></li>
<li><span style="font-size: 18px;">If fewer than<strong> 3</strong> matching sentences exist, return all of them.</span></li>
</ul>
<p><strong><span style="font-size: 14pt;">Examples:<br></span></strong></p>
<pre><span style="font-size: 18.6667px;"><strong>Input:</strong> </span><span style="font-size: 18.6667px;">sentences[] = ["geeks for geeks", "geeks quiz", "geeksforgeeks", "geek"], </span><span style="font-size: 18.6667px;">times[] = [5, 3, 2, 2]</span><br><span style="font-size: 18.6667px;"><strong>Operations:</strong><br></span><span style="font-size: 18.6667px;">input('g')<br></span><span style="font-size: 18.6667px;">input('e')<br></span><span style="font-size: 18.6667px;">input('e')<br></span><span style="font-size: 18.6667px;">input('#')</span><br><strong><span style="font-size: 18.6667px;">Output:</span></strong><br><span style="font-size: 18.6667px;">["geeks for geeks", "geeks quiz", "geek"]<br></span><span style="font-size: 18.6667px;">["geeks for geeks", "geeks quiz", "geek"]<br></span><span style="font-size: 18.6667px;">["geeks for geeks", "geeks quiz", "geek"]<br></span><span style="font-size: 18.6667px;">[]</span><br><strong><span style="font-size: 18.6667px;">Explanation:</span></strong><br><span style="font-size: 18.6667px;">Initially, the system is populated with the given sentences and their corresponding frequencies from times.</span><br><span style="font-size: 18.6667px;">After typing 'g', all four sentences match the prefix "g". The top three are selected by frequency, and ties are broken using ASCII order, so "geek" appears before "geeksforgeeks".</span><br><span style="font-size: 18.6667px;">After typing 'e' and then another 'e', the current prefix becomes "ge" and "gee" respectively. The same three sentences remain the highest-ranked matches.</span><br><span style="font-size: 18.6667px;">When '#' is entered, the current query "gee" is stored in the system with frequency 1, and an empty list is returned.</span></pre>
<p><strong><span style="font-size: 18.6667px;">Constraints:<br></span></strong></p>
<p><span style="font-size: 18.6667px;">n == sentences.length == times.length<br></span><span style="font-size: 18.6667px;">1&nbsp;≤ n&nbsp;≤&nbsp;100<br></span><span style="font-size: 18.6667px;">1&nbsp;≤ sentences[i].length&nbsp;≤&nbsp;100<br></span><span style="font-size: 18.6667px;">1&nbsp;≤ times[i]&nbsp;≤&nbsp;50<br></span><span style="font-size: 18.6667px;">c is a lowercase English letter, a space ' ', or the special character '#'.<br></span><span style="font-size: 18.6667px;">Each input query ends with '#'.<br></span><span style="font-size: 18.6667px;">Each query has length in the range [1, 200].<br></span><span style="font-size: 18.6667px;">The words in each query are separated by single spaces.<br></span><span style="font-size: 18.6667px;">Let k denote the average length of the stored sentences.<br></span><span style="font-size: 18.6667px;">Let m denote the total number of calls made to input().</span></p></div><p><span style=font-size:18px><strong>Company Tags : </strong><br><code>Cisco</code>&nbsp;<code>Facebook</code>&nbsp;<code>Amazon</code>&nbsp;<code>Microsoft</code>&nbsp;<code>Google</code>&nbsp;<code>Uber</code>&nbsp;<br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Strings</code>&nbsp;<code>Trie</code>&nbsp;<code>Advanced Data Structure</code>&nbsp;
